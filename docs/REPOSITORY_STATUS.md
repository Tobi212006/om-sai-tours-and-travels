# Repository status

This repository is the source-control home for the Om Sai Tours and Travels academic project.

## Included in this commit

- Expo / React Native mobile app configuration and API client
- Node.js / Express backend package configuration and environment templates
- Booking traveler-count validation test
- Existing project overview, upload checklist and README

## Important status note

The project is a prototype and must be reviewed and tested before being presented as production-ready. Configure local environment variables from the example files, never commit real credentials, and verify authentication, authorization, booking validation, payments and admin access before deployment.
